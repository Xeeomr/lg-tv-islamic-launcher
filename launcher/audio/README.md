# أصوات الأذان

المضمّن في المستودع تسجيلات بتراخيص مفتوحة فقط:

| الملف | المصدر والترخيص |
| --- | --- |
| `adhan-egypt.mp3` | عبد الناصر حرك · archive.org (Public Domain Mark) |
| `adhan-sabah-fakhri.mp3` | صباح فخري · ويكيميديا كومنز (Public domain) |
| `adhan-beautiful.ogg` | ويكيميديا كومنز (CC0) |

لإضافة أذان الحرم المكي أو المدني أو العفاسي أو الأقصى أو غيرها، ضع الملف هنا **إن كان لديك حق استخدامه**،
بأحد الأسماء المعروفة في `voices.json` (مثل `adhan-makkah.mp3`) ليظهر باسمه العربي، أو بأي اسم آخر ليظهر باسم الملف.
ثم أعد تشغيل `./install.sh <IP الشاشة>`. لا ترفع تسجيلات غير مرخصة إلى المستودع (هي مستبعدة في `.gitignore`).
