# Clean Your TV — 사용자 안내

No-root와 Root는 서로 다른 TV 환경에 맞는 동등한 선택지입니다. LG Developer Mode를 사용하면 No-root를, 기존 root SSH 접근 권한이 있으면 Root를 선택하세요. 호환성과 테스트 범위는 각 버전마다 다릅니다.

## 설치 전 준비

이 안내서는 **[v1.2.0 안정 버전](https://github.com/Razdva122/clean-your-tv-lg-webos/releases/tag/v1.2.0)**을 설명합니다. `releases/latest/download` 링크는 게시된 안정 버전을 제공합니다. [설치 안내](../INSTALL.md)와 [릴리스 안내](../RELEASE-1.2.0.md)를 확인하세요.

릴리스 구성: cytv **0.3.1**, Home **1.4.1**, Home Helper **0.6.19**, Root **0.3.0**, Home Updater 및 Root Updater **0.2.1**, Android **0.2.1-preview**(버전 코드 **10**), System Updater 감독 서비스 **1.0.0**, 프로토콜 **1**.

TV를 켜고 컴퓨터와 같은 신뢰할 수 있는 로컬 네트워크에 연결하세요. 설치 후에는 컴퓨터를 꺼도 됩니다. 호환성은 모델, 펌웨어, 리모컨에 따라 다릅니다. Root는 실제 기기 검증이 남아 있습니다.

- **No-root:** LG Developer Mode와 Key Server를 켜세요. TV에 표시된 암호 문구를 입력하고 별도로 표시되는 페어링 요청을 TV에서 승인하세요. Developer Mode를 계속 활성화해야 합니다. 세션이 만료되면 설치한 앱이 삭제될 수 있습니다. 베타 자동 갱신을 켰더라도 공식 타이머를 확인하세요. Helper의 상태 감시에는 로컬 네트워크가 필요합니다.

업데이트된 No-root Helper는 TV의 Node.js 0.12.2 이상이 필요합니다. 설치 프로그램은 설치 전에 TV 런타임을 확인합니다. 이전에 배포된 패키지에 이 호환성이 자동으로 적용되지는 않습니다. 입력 장치 접근, 대기 모드 복귀 및 콜드 부팅은 모델별로 확인해야 합니다.

- **Root:** 기존 root SSH 접근 권한이 필요합니다. 설치 프로그램은 TV를 루팅하지 않습니다. 이미 루팅한 TV에는 Developer Mode를 켜지 마세요. root 접근 및 복구 서비스를 유지하세요.

## Root용 선택적 Python 런타임

Root에는 TV의 Python 3.9 이상이 필요합니다. 설치 프로그램은 버전 번호뿐 아니라 `json`, `fcntl`, 잠금, 파일 및 하위 프로세스 등 필요한 모듈과 동작을 실제로 확인합니다. 기존 인터프리터가 적합하면 Python을 추가로 다운로드하지 않습니다. 적합한 Python이 없으면 설정 과정에서 컴퓨터나 Android가 URL·크기·SHA-256이 고정된 **ARMv7 soft-float용 CPython 3.13.17**을 받아 기존에 신뢰한 SSH 연결로 전송할 수 있습니다. 일반 데스크톱/Android 설치 패키지에 이 압축 파일은 포함되지 않으며, 이 단계에서는 TV의 인터넷 연결이 필요하지 않습니다.

추가 다운로드는 약 **26.3 MB**, 정규화한 SSH 전송은 **51.5 MB**, 설치 파일은 **119.3 MB**입니다. 준비 작업에는 TV 여유 공간 **320 MiB**가 필요합니다. 활성화 전에 로더와 라이브러리 호환성을 확인합니다. 런타임은 `/var/lib/clean-your-tv-python/` 아래의 전용 버전 슬롯에 설치되며 시스템 Python, libc, 전역 PATH를 바꾸지 않습니다. Root/System Updater에는 여전히 root 권한, 적절한 webOS 서비스와 Node.js **8 이상**이 필요합니다. No-root Helper는 Node.js **10 이상**이 필요합니다.

인터넷이 되는 컴퓨터에서 TV를 검색하거나 연결하지 않고 검증된 캐시를 준비할 수 있습니다.

```sh
./cytv --prepare-python-runtime --data-dir /path/to/private-cache
```

설치할 때 같은 `--data-dir`를 사용하세요. 캐시를 옮길 때는 SSH 키나 평소 프로필이 없는 별도의 비공개 폴더를 준비하세요. `status`, `doctor`, `restore`, `uninstall`은 Python을 자동 다운로드하지 않습니다. 앱을 제거한 뒤에도 Root, 업데이터 또는 복구 기록이 사용하는 런타임 슬롯을 유지하세요. 자세한 내용은 [선택적 런타임 안내](../OPTIONAL-PYTHON.md)를 참조하세요.

## 설치와 언어 선택

- **Windows x64:** `cytv-windows-x64-desktop.zip`을 다운로드하고 파일 탐색기에서 **모두 추출**을 선택한 다음 `cytv-desktop/cytv-desktop.exe`를 여세요. `_internal` 폴더를 옆에 그대로 두세요. Windows 게시자 서명은 구성되어 있지 않습니다. 별도 콘솔은 `cytv-windows-x64.exe`입니다. 아래 PowerShell 명령은 이름을 `cytv.exe`로 바꾸고 `.\cytv.exe`로 실행하세요.
- **macOS 13 이상:** Apple Silicon은 `cytv-macos-arm64.zip`, Intel은 `cytv-macos-x64.zip`을 푸세요. `cytv.app`을 응용 프로그램 폴더로 옮겨 열고 로컬 네트워크 접근을 허용하세요. 신뢰할 수 있는 다운로드가 차단되면 개인정보 보호 및 보안 → 확인 없이 열기를 사용하세요. Gatekeeper를 끄지 마세요. 구형 시스템 검증은 완료되지 않았습니다.
- **Linux x64:** Ubuntu 22.04 이상, Debian 12 이상 또는 Mint 21 이상에서 `cytv-linux-x64.deb`를 그래픽 패키지 관리자로 설치하고 앱 메뉴에서 Clean Your TV를 여세요. 라이브러리 설치에 인터넷이 필요할 수 있습니다. Linux ARM 패키지는 없습니다. 독립 실행 파일 `cytv-linux-x64`는 CLI입니다. 그래픽 앱은 `.deb`를 사용하세요.

[Android 설치 프로그램](../../android/README.md)은 10개 인터페이스 언어를 모두 지원합니다. 오른쪽 위에 현재 언어가 표시되며, 누르면 다른 언어를 선택할 수 있습니다. 선택한 언어는 휴대전화에 저장됩니다.

Android에서는 연결 중에도 선택한 유지관리 작업이 표시되며 설치 단계 대신 해당 작업의 진행 상태가 표시됩니다. 휴대전화의 시스템 글꼴을 사용하고 레이블과 도움말 글자를 키웠습니다.

데스크톱 설치 마법사는 처음에 시스템 언어를 사용하고 직접 선택한 언어를 저장합니다. TV에서는 **설정 → 언어**에서 언어를 고르거나 시스템 언어를 따르는 자동 옵션을 선택하세요. 설치 프로그램과 TV의 언어 설정은 별개입니다. 지원 코드는 [언어 목록](../LANGUAGES.md)을 참조하세요.

macOS/Linux에서 별도로 받은 CLI는 압축을 푼 폴더에서 실행하세요.

```sh
chmod +x cytv
./cytv --language ko install
```

TV를 선택하거나 IP를 입력하고 에디션과 설치 요약을 확인하세요. 새로운 SSH 신원은 신뢰할 수 있는 네트워크의 본인 TV인 경우에만 승인하세요. 저장된 키가 바뀌면 접근이 차단됩니다. Root는 복구 기능을 준비한 뒤 시험 기간이나 유지 확인 없이 Home을 바로 활성화합니다. 방향키, OK, Home, 뒤로/취소, 음량, 대기 모드 복귀와 전원을 완전히 껐다 켜는 동작을 확인하세요.

Root 제거가 중단되면 앱에서 제거를 다시 선택하세요. TV의 보존된 기록과 패키지 상태를 확인한 후 계속하며, 완료된 제거는 다시 요청하지 않습니다. 작업이 진행 중이면 1분 기다리세요. 결과를 확인할 수 없으면 TV를 재시작하고 다시 확인하세요. 지원을 위해 진단 보고서를 보관하세요.

## 사용과 복구

방향키로 선택하고 OK로 실행합니다. OK를 길게 눌러 순서를 바꿉니다. 뒤로를 짧게 누르면 앱의 탐색과 종료 확인이 유지됩니다. Home 제어가 활성화되면 짧은 Home으로 런처를 엽니다. 새 빌드에서는 뒤로를 1.2초 동안 누르면 LG Home이 한 번 열립니다. Home 제어 스위치와 설정은 바뀌지 않습니다.

**새 빌드에서는 2초 안에 Home을 세 번 짧게 누르세요.** 매번 버튼을 놓아야 합니다. 설정을 지우지 않고 LG Home으로 복귀하며 Home 제어를 중지합니다. No-root Helper 0.6.13 이하에서는 대신 Home을 약 2초 동안 누릅니다. Home 길게 누르기는 Root의 비상 복구 동작이 아닙니다.

No-root는 LG 앱 목록에서 **Home Helper**를 열어 재개하세요. Home만 열어서는 중지가 해제되지 않습니다. Root는 Home 설정에서 **Home 변경**을 켜서 재개하세요. **LG Home 열기**는 Home의 연결 대상을 바꾸지 않고 LG Home을 한 번 엽니다. LG Home을 계속 사용할 기본 대상으로 복원하려면 **Home 변경**을 끄거나 `cytv restore`를 실행하세요. 두 제어 프로그램을 동시에 실행하지 마세요. 문제가 반복되면 LG Home을 유지하세요.

```sh
./cytv --language ko status
./cytv --language ko doctor --report
./cytv --language ko restore
./cytv --language ko uninstall
```

작업이 중단되면 재시도 전에 `status`를 실행하고 로그를 보관하세요. `restore`는 앱을 삭제하지 않고 LG Home을 복구합니다. `uninstall`은 복구 후 제거합니다. Root 복구 데이터는 의도적으로 남습니다. 재설치를 강제하려고 삭제하지 마세요. 진단 보고서는 공유 전에 검토하고 키나 프로필 폴더는 공개하지 마세요.

## 업데이트와 제거

연결 후 cytv는 설치 버전 → 포함 버전을 표시하고 최초 설치, 재설치, 이전 버전 설치를 구분합니다. 확인 전에 요약을 읽으세요. `--yes`를 사용해도 호환성 검사는 유지됩니다. 작동하는 패키지와 설정의 비공개 복사본을 보관하세요. 컴퓨터에서 패키지를 바꾸기 전 No-root Helper를 중지하고, 먼저 제거하지 마세요. 실행 중인 Root에 IPK 하나만 덮어쓰지 말고 cytv의 정해진 절차를 사용하세요. 데스크톱 앱 제거는 TV 앱을 제거하지 않습니다.

후보는 설정 → 소프트웨어 업데이트에 **모두 업데이트**를 추가합니다. 독립적인 System Updater가 에디션에 맞는 서명된 릴리스 묶음을 검증합니다. root TV의 No-root 에디션은 Home, Helper, Home Updater를, Root 에디션은 Root Home, Root Updater와 Home 제어/복구 런타임을 업데이트합니다. TV에서 설치하려면 **root와 Homebrew Channel**, 적합한 Python, Node.js 8 이상 및 작동하는 webOS 설치 서비스가 필요합니다. root가 없는 TV는 컴퓨터를 사용하세요.

새로 설치할 때는 후보의 전체 설치 프로그램으로 Home과 해당 에디션의 복구 Updater를 준비하세요. 이 전환 버전은 안정 버전 업데이트 피드에서 제공되지 않습니다.

Root가 이미 설치되어 있고 Root Updater가 남아 있으면 일반 재설치가 의도적으로 차단될 수 있습니다. 먼저 `status`와 진단을 실행한 뒤 기존 Updater의 트랜잭션과 복구 상태를 확인하세요. 진행 중이거나 결과가 불확실한 작업은 해당 기존 버전의 복구 절차로 해결해야 합니다. 새 기반 구조로 전환하는 과정은 TV의 실제 설치 상태에 따라 검토해야 합니다. 기록을 삭제하거나 `--yes`, 개별 IPK, 기존 OTA로 차단을 우회하지 마세요. 앱만 바꾸는 OTA는 새 기반 구조를 설치하지 않습니다. [기존 TV 확인 단계](../UPDATES.md#one-time-computer-preparation)를 따르세요.

Home `systemUpdateProtocol = 1`과 해당 복구 Updater가 있는 호환 구성을 확인한 뒤에만 컴퓨터에서 감독 서비스를 활성화하세요. 설치 프로그램에서 모든 TV 구성 요소의 업데이트를 활성화하는 항목을 선택하세요. 저장된 root SSH 연결을 사용하는 Root 명령은 다음과 같습니다.

```sh
./cytv --language ko enable-system-updates --edition root --host TV_ADDRESS
```

root TV의 No-root는 컴퓨터에서 Home/Helper/Home Updater를 먼저 준비한 뒤 [업데이트 안내의 root SSH 별칭 절차](../UPDATES.md#one-time-computer-preparation)를 따르세요. 감독 서비스는 실제 설치된 구성 요소를 검증된 복구 기준으로 저장합니다. 기존 앱 전용 OTA는 새 Python 런타임, 감독 서비스나 업데이터 기반 구조를 설치하지 않습니다. 준비가 끝나면 공통 업데이트 경로를 사용하세요. 충돌하는 기존 설치 방식은 거부됩니다.

설치 전에 확인을 요청하고 설치 후에는 시작 상태를 자동 확인합니다. 프로필과 설정을 보존하며 명시적 중지나 비상 중지를 해제하지 않습니다. 위/아래로 변경 내용을 읽고 왼쪽/오른쪽으로 고정된 작업 버튼을 선택하세요. 상태 갱신은 리모컨 선택을 유지합니다. 주황색 점은 컴퓨터 설치가 필요한 경우를 포함해 새 버전을 알립니다. Updater의 복구에서 상태와 보관된 이전 버전을 확인하세요. 시스템 롤백은 이전 구성 요소 전체와 저장된 프로필을 복원하므로 업데이트 후 바꾼 설정이 사라질 수 있습니다. 자동 시작 확인 뒤에도 다음 트랜잭션까지 롤백이 유지됩니다.

작업이 끊기면 `status`를 실행하고 작업 기록과 복구 데이터를 보관하세요. 설치 결과가 불확실하면 재설치와 롤백이 차단됩니다. 버전이 읽힌다는 것만으로 설치 완료를 판단할 수 없습니다. 재시도를 강제하려고 기록, 잠금 또는 Python 슬롯을 삭제하지 마세요. `doctor --report`는 실패한 Root 요구 사항을 각각 표시하고 자격 증명이나 원시 출력 없이 숫자 SSH 종료 코드를 기록합니다. 공유 전 보고서를 검토하세요.

## 하드웨어 검증 범위

OLED55C3RLA / 펌웨어 43.21.71 / webOS 11.2.0에서 Root 0.2.0, Root Updater 0.2.0, 감독 서비스 1.0.0을 확인했습니다 (`d344d92`, 제품 내용은 `4b66951`과 동일). 리모컨, Home 세 번 및 재개, Emby를 70초간 열어 둔 대기/깨우기, 버전 메뉴와 피드 사용 불가 안내가 통과했습니다. 실제 전원 차단 후 부팅, TV의 Helper 0.6.19, UK6540PTD, 전체 서명 시스템 업데이트/롤백은 시험하지 않았습니다. 안정 버전은 이 제한된 근거로 게시되며 다른 모델은 검증되지 않았습니다.

No-root는 TV 셸 ABI를 검사하며 ARM32 사용자 환경이 확인된 경우에만 64비트 커널을 허용합니다. 모델명이나 `armv7l`만으로 호환성을 보장할 수 없습니다. 이전 검증은 해당 기기와 패키지 범위에 한정됩니다.

No-root: Home 설정 → 개발자 모드에서 베타 자동 갱신, 세션 확인, 진단을 엽니다. 공식 타이머를 계속 확인하세요. Home Helper는 상태를 표시하며 중지 후 다시 시작할 때 확인을 요청합니다.

영문 기술 안내: [데스크톱](../DESKTOP_INSTALL.md), [CLI](../CLI.md), [수동 설치](../MANUAL_INSTALL.md), [복구](../RECOVERY.md), [에디션](../EDITIONS.md), [업데이트](../UPDATES.md).

감독 서비스 설정 직후 Root에 `Denied methods call status`가 표시되면 Home Root를 한 번 닫고 다시 연 뒤 업데이트를 확인하세요. 계속되면 진단과 복구 상태를 보관하세요.

1.2.0 (#51): TV가 패키지를 거부하면 진단 JSON에는 작업 분류, 범위가 제한된 숫자 오류·상태 코드, 허용된 패키지 상태 및 불리언 결과만 저장됩니다. TV 오류 원문, 경로 및 앱 ID는 제외됩니다. 공유 전에 보고서를 검토하세요. 자동 재시도는 없으며 UN70006LA 설치 실패가 해결되었다고 확인된 것은 아닙니다.

1.2.0 (#59): Helper 상태를 확인할 수 없어도 확인 후 **Helper 시작**을 선택할 수 있습니다. 타일을 여는 것만으로 Helper가 다시 시작되거나 비상 정지가 해제되지는 않습니다. Home 설정을 사용하려면 제어가 응답해야 합니다.

1.2.0 (#55): Root는 설치 전에 마이그레이션 데이터를 검증합니다. 프로비저닝 전에 중단된 설치는 생성되지 않은 LS2 스냅샷 없이 제거할 수 있으며, 일반 cytv 보관 및 재설치를 위한 검증된 기록을 유지합니다. 이후 단계에서 스냅샷이 없거나 증거가 충돌하면 정리는 계속 차단됩니다. 새 드라이버가 필요하며 OLED Flex 복구 서비스 시작 실패는 아직 해결되지 않았습니다.

## 1.2.0의 LG 펌웨어 차단

Root 전용: Home 설정 → LG 펌웨어 업데이트에서 기존 Homebrew Channel 설정을 변경합니다. 펌웨어 보안 업데이트도 포함되며 Clean Your TV 업데이트는 별도입니다. 켜거나 끈 후에는 TV를 실제로 다시 시작해야 하며 대기 모드로는 부족합니다. 스위치는 저장된 설정을 표시하며 실제 차단 여부를 보장하지 않습니다. 일부 TV는 차단 전에 업데이트를 확인하므로 알림이 남거나 공유기 차단이 필요할 수 있습니다. CYTV 제거 또는 롤백 후에도 Homebrew 설정은 유지됩니다. 사용할 수 없거나 결과가 확인되지 않으면 Homebrew를 확인하고 상태를 새로 조회하세요. TV 확인 범위는 승인 기록을 참조하세요.
