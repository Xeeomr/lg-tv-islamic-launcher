# cytv Implementation Plan

Current edition wording (2026-10-24): No-root and Root are equal options for LG Developer Mode and existing root SSH environments. Historical “Root Preview” naming and edition recommendations below are superseded; recorded hardware-validation limits still apply.

> **For agentic workers:** Execute inline with executing-plans. The user explicitly authorized implementation in this chat.

**Goal:** Deliver a single-file installer with both edition workflows and native build automation.

**Architecture:** A small Python package separates terminal interaction, private local state, SSH/SSAP transport, IPK personalization and edition operations. Reuse the Root device driver unchanged. Build helper and public payload at build time, then freeze separately on each OS.

**Tech Stack:** Python 3.11+, Paramiko, websockets, psutil, PyInstaller, Zig 0.14.1 at build time only.

**Spec:** `docs/superpowers/specs/2026-10-23-cytv-design.md`

## Global Constraints

- Windows x64, Linux x64, macOS ARM64 and macOS x64 executables; no end-user development tools.
- Never contact a real TV in automated tests. Subsequent user requests authorized read-only manual network discovery checks and separate TV maintenance.
- Preserve Root recovery and emergency exit. User requested removal of the timed trial: one on-TV activation automatically verifies readiness and records persistent intent.
- Never print credentials, automatically trust changed SSH keys or retry an uncertain install.
- No-root Developer Mode and Root Preview acceptance limitations stay visible.
